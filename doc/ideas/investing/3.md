Indicator 3 memory

Step 3 — HBM / Memory Sheet
Purpose: detect whether AI-memory demand remains tight or whether memory supply is beginning to catch up.
Cadence:
* Monthly: HBM market observations and server DRAM prices
* Quarterly: memory-maker inventory data
1. Memory-maker inventory days — primary quantitative signal
Companies:
* SK Hynix
* Samsung
* Micron
Track:
Quarter	SK Hynix Inventory Days	Samsung Inventory Days	Micron Inventory Days	Notes	Source	Last Updated
Primary sources:
* Company quarterly earnings releases
* 10-Q / 10-K / annual and quarterly reports
* Investor presentations
Inventory days is the primary metric. Absolute inventory can be retained as supporting data but isn’t necessary for the core dashboard.
Signal:
* Low/stable inventory days → tight supply / strong demand
* Rising inventory days → potential normalization
* Rapidly rising inventory days → potentially bearish
Company commentary should be captured when it materially explains the inventory movement.
2. HBM pricing — qualitative primary signal
There doesn’t appear to be a sufficiently transparent, standardized public HBM price series to justify pretending we have precise monthly prices.
Track:
Month	HBM Price Trend	Generation	Source	Notes	Last Updated
	Rising / Stable / Falling	HBM3E / HBM4
Sources:
* TrendForce
* Other credible semiconductor research / industry sources when necessary
* Memory-company commentary as supporting evidence
Don’t manufacture a numerical price when the source only provides directional information.
The key is consistency: if multiple credible reports indicate HBM contract prices are rising or falling, record that direction and the evidence.
3. Server DRAM — bonus confirmation
Track server DDR5 / server DRAM contract prices monthly.
Month	Server DRAM Price Trend	Source	Last Updated
	Rising / Stable / Falling	TrendForce
Primary source:
* TrendForce DRAM pricing
This is supporting evidence rather than a direct AI-demand indicator because conventional DRAM has applications far beyond AI.
What we’re looking for
Strong AI-memory demand:
HBM prices ↑ + inventory days low/stable + server DRAM prices ↑
Potential deterioration:
HBM prices ↓ + inventory days ↑ + server DRAM prices ↓
The combination matters much more than any individual observation.
Source hierarchy
Highest priority
1. SK Hynix / Samsung / Micron earnings and filings
2. TrendForce
Secondary3. Other reputable semiconductor research4. Company/investor commentary
The sheet stays deliberately small: hard inventory data + qualitative HBM pricing + broader DRAM pricing.
